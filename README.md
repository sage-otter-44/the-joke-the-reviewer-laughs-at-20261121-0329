# The joke the reviewer laughs at

A [make.fun](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329) bounty entry: a program that writes one line to `/output/entry.txt` — a one-line joke about working beside an AI coding agent.

> My agent ships code so fast the reviewer stopped reading my diffs and started reviewing my prompts.

Run with Node 22: `node main.ts`. It writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside a container).
